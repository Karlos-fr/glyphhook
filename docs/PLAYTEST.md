# Glyphhook v0.4 Playtest Matrix

All gameplay rooms are fixed 64 × 36 cells and must fit entirely on screen.

## Room framing

- [ ] Entire 64×36 room is visible on desktop 16:9
- [ ] Entire room remains visible on wider screens with horizontal letterboxing/centering
- [ ] Entire room remains visible on taller screens with vertical letterboxing/centering
- [ ] Mobile landscape shows the complete room
- [ ] Mouse/touch aim coordinates remain aligned with anchors after fitting

## Grapple

- [ ] Click/hold Hook attaches to the highlighted anchor
- [ ] Holding Hook visibly reels the player toward the anchor
- [ ] Player can gain height from a standing/running attach
- [ ] Left/right swing pumping still adds tangential speed
- [ ] Releasing Hook preserves tangential momentum
- [ ] W reels faster; S/Down lets rope out
- [ ] Multiple anchors can be chained without exceeding hook range
- [ ] Corner wrapping/unwrapping remains stable

## Controls

- [ ] Space jumps
- [ ] Arrow Up jumps
- [ ] A/D and Left/Right move
- [ ] Mouse click holds/releases Hook
- [ ] Mobile Hook can be held before/while aiming
- [ ] Bubble works while airborne
- [ ] Esc/pause does not lose the run

## Rooms

- [ ] 00 Movement Lab — run, jump, hold Hook, release, Bubble
- [ ] 01 Runway — all four lava jumps are reachable without Hook
- [ ] 02 First Swing — Hook lifts the player onto the central platform
- [ ] 03 Release — Hook + release reaches the landing route
- [ ] 04 Transfer — consecutive anchors are chainable
- [ ] 05 Bubble — gaps are solvable with jump + Bubble
- [ ] 06 Combo — Hook and Bubble can be combined
- [ ] 07 Needle — narrow landings are reachable
- [ ] 08 Ascent — vertical chain can be completed with active reeling
- [ ] 09 Final Circuit — full sequence is possible without leaving the room

## Visual reference

- [ ] World uses true text characters (# @ O ^ ! E □)
- [ ] Repeated wall glyphs read densely with small visual gaps
- [ ] UI art direction remains separate from gameplay colors
- [ ] Rope is visibly segmented rather than a smooth line
